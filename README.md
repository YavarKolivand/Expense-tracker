# Expense Tracker 💰

A modern and responsive **Expense Tracker** built with **React, TypeScript, React Router, and Tailwind CSS**.

The application helps users manage their income and expenses through a clean dashboard and an intuitive transaction management system.

## ✨ Features

* 📊 Dashboard with income, expenses, balance and transaction statistics
* ➕ Create new transactions
* ✏️ Edit existing transactions
* 🗑️ Delete transactions
* 🔍 Search and filter transactions
* 🌓 Light / Dark mode
* 💾 Persistent data with Local Storage
* 📱 Fully responsive design
* 🔔 User feedback with Toast notifications
* 🧭 Multi-page navigation with React Router

## 🛠️ Technologies

* React
* TypeScript
* React Router
* Tailwind CSS
* React Toastify
* Local Storage

## 🚀 Getting Started

```bash
npm install
npm run dev
```

This project was developed to practice building a real-world React application with:

* Responsive UI development
